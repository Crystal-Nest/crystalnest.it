# Crystal Nest

The official website for Crystal Nest, featuring Minecraft mods, development tools, and resources for modders.

_Desktop and mobile friendly!_

## [Mod Generator](https://crystalnest.it/#/generator)

Create your own Minecraft mod with the Crystal Nest Mod Generator!

Based on the [Crystal Nest Cobweb Mod Template](https://github.com/Crystal-Nest/cobweb-mod-template), it automatically generates a customizable mod template using the information you provide.

To get started, create a repository from the official template, then use the generator to update each branch with your custom configuration.

## [Mod Semantic Versioning](https://crystalnest.it/#/versioning)

Learn about the Crystal Nest versioning standard, how to interpret mod version numbers, and whether it might be useful for your own projects!

## [Mod Showcase](https://crystalnest.it/#/mods)

Explore the Crystal Nest mod collection! Browse released mods, find detailed information, and access relevant links, all through a responsive interface that works across different devices.
